A consistent review, line by line

The supplied instructions set a clear workflow: assess every eligible row, explain the judgment in words, and suggest an alternative when it adds value.

1

Read in context

Compare source and translation while tracking the speaker and dialogue flow.

2

Respect skips

Do not review rows explicitly marked TRUE in the skipped column.

3

Score and explain

Assign a 1–5 score and write a concise comment for each reviewed row.

4

Offer a variant

Provide a proposed translation when a specific improvement is warranted.

A usable evaluation record

Each finding was designed to be easy to review, understand, and act on.

  • Line-level scores on the required scale
  • Written comments for reviewed rows
  • Clear criterion labels, no numeric sub-scores
  • Proposed variants for targeted improvements
  • Rows marked as skipped left unevaluated
  • Accepted translations documented alongside issues

Outcome

A traceable quality assessment that distinguishes accurate translations from narrower issues of register, naturalness, context, or source formatting—turning subtle judgments into actionable evaluation notes.
